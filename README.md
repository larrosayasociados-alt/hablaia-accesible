# hablaia-accesible

Servidor de **prueba** para el cliente Xiaozhi ESP32 `v2.5.2`. Habla el protocolo de la placa: OTA con URL de WebSocket y token, y el canal de audio Opus con JSON.

No está desplegado. No usa un nombre público de producción. Las pruebas de este repositorio no demuestran una conversación en el aparato.

La guía está en [docs/SERVIDOR.md](docs/SERVIDOR.md). El arranque local es `server/`.

El firmware de la placa es otro cambio. Este servidor no lo modifica, no flashea y no toca el sitio que ya está publicado.
